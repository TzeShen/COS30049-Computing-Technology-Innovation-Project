How Checkie works

Checkie never fetches the page behind a URL. Every signal below comes from reading the address itself, locally, using the same model trained in this project.

1

Parse the URL

The address is broken into its scheme, host, path and query — no request is ever sent anywhere.

2

Extract signals

28 offline features are computed: length, IP-literal hosts, look-alike characters, suspicious TLDs, subdomain depth and more.

3

Score with a trained model

A Random Forest classifier, trained on labelled phishing and legitimate URLs, turns those signals into a trust score.

4

Explain the result

The signals that actually drove your score are shown back to you, in plain language — not a black-box number.
